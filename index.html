Quiet Design System

Quiet 是一套安静的网页设计风格：一栏文字，四级灰度，三种字重。

它不限定用途。个人主页、产品官网、文档、应用里的列表和设置页，都用同一套规则做出来。

下面每个示例都是一个完整的页面，可以直接点进去看。样式和用法都在 GitHub 上。

示例

  • 个人主页 引言、经历和文章
  • 产品首页 介绍、功能、价格和常见问题
  • 应用列表 标签页、数据概览和表格
  • 设置页 表单、开关和确认对话框
