顶栏与导航

整个网站的导航只有两样东西：粘在顶部的一行面包屑，和点菜单按钮后盖住整页的导航层。没有侧边栏，没有页脚导航。

顶栏 .q-topbar

菜单按钮、站点名、一条斜杠、当前页。56px 高，没有边框和阴影，底色和页面相同。

  <button class="q-icon-button" type="button" aria-label="菜单">
    <svg>…</svg>
  </button>
  <a href="../">潮池</a>
  <span class="q-topbar-sep">/</span>
  <a href="./">文档</a>
  <button class="q-icon-button q-topbar-end" type="button" aria-label="切换深浅色">
    <svg>…</svg>
  </button>
</header>
  • 面包屑最多两级：站点名和当前所在的栏目。
  • 最右边可以放一个图标按钮，加上 .q-topbar-end 推到右侧。最多放一个，比如切换深浅色，或者当前用户的头像。

全屏导航 .q-nav

点左上角的菜单按钮可以看到真实的效果。它盖住整个页面，底色和页面相同。下面是它里面的内容：

示例 应用列表 设置页 
<nav class="q-nav">
  <div class="q-nav-group">
    <a class="q-nav-link" href="../">首页</a>
    <a class="q-nav-link" href="./" aria-current="page">文档</a>
  </div>
  <div class="q-nav-group">
    <span class="q-nav-label">示例</span>
    <a class="q-nav-link" href="../examples/app.html">应用列表</a>
    <a class="q-nav-link" href="../examples/settings.html">设置页</a>
  </div>
</nav>
  • 链接是 20px 半粗的灰色字，当前页（aria-current="page"）和悬停时变成主色。
  • 用 hidden 属性控制显示和隐藏。
  • 链接分组，组与组相距 32px，每组可以有一个 14px 的灰色小标签。
  • 应用的全部导航都放在这里。
