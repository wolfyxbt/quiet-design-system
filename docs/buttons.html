组件

按钮

页面上能按的东西有四种：按钮、小胶囊、图标按钮和图标链接。它们都只用黑白灰。

按钮 .q-button

36px 高、全圆角、16px 中等字重。<a> 和 <button> 都能用。

免费开始 查看价格 
<div class="q-actions">
  <a class="q-button q-button--primary" href="../examples/app.html">免费开始</a>
  <a class="q-button" href="../examples/product.html">查看价格</a>
  <button class="q-button q-button--ghost" type="button">取消</button>
  <button class="q-button q-button--danger" type="button">删除</button>
</div>
  • 默认 白底，细描边，轻投影。大部分按钮都是它
  • 主按钮 实心。一个页面最多一个
  • 幽灵按钮 只有灰色文字，用于「取消」
  • 危险按钮 默认按钮，文字变红
  • 一个页面最多一个主按钮。这一页为了展示放了一个，真实页面里它应该是页面上最重要的那个操作。
  • 不做彩色的实心按钮。删除这类操作只把文字变红。
  • 按钮文字两到四个字，动词开头。
  • 几个按钮用 .q-actions 排成一排，相距 8px。

禁用

<div class="q-actions">
  <button class="q-button q-button--primary" type="button" disabled>保存修改</button>
  <button class="q-button" type="button" disabled>导出</button>
</div>

小胶囊 .q-pill

小一号的默认按钮：28px 高、14px 字、浅灰色文字。用于贴着内容的小操作，比如点赞数、计数、翻页。不拿它当页面上的主要按钮。

<div class="q-actions">
  <button class="q-pill" type="button">
    <svg>…</svg>
    128
  </button>
  <button class="q-pill" type="button">上一页</button>
  <button class="q-pill" type="button">下一页</button>
</div>

图标按钮 .q-icon-button

36px 的圆，平时完全透明，悬停才出现一层很淡的底色。用在顶栏里。一定要写 aria-label。

<div class="q-actions">
  <button class="q-icon-button" type="button" aria-label="菜单">
    <svg>…</svg>
  </button>
  <button class="q-icon-button" type="button" aria-label="切换深浅色">
    <svg>…</svg>
  </button>
</div>

图标链接 .q-icon-links

一排 28px 的线性图标，最浅的灰，悬停变成主色。用在介绍页的引言下面，放社交账号、源码、下载这类链接。第一个图标向左偏 8px，让图形和上方的文字左对齐。

<ul class="q-icon-links">
  <li>
    <a class="q-icon-link" href="https://github.com/wolfyxbt/quiet-design-system" aria-label="源码">
      <svg>…</svg>
    </a>
  </li>
  <li>
    <a class="q-icon-link" href="https://github.com/wolfyxbt/quiet-design-system/blob/main/DESIGN.md" aria-label="设计规范">
      <svg>…</svg>
    </a>
  </li>
</ul>
