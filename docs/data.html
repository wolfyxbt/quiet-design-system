组件

数据

应用页里展示数据的几样东西。它们放在一起的样子见应用列表。

标签页 .q-tabs

一排 16px 的灰色文字，当前项变成主色。没有下划线和底色，做法和导航链接一样。用来切换同一份数据的不同筛选。

<div class="q-tabs" role="tablist">
  <button class="q-tab" type="button" role="tab" aria-selected="true">全部</button>
  <button class="q-tab" type="button" role="tab" aria-selected="false">草稿</button>
  <button class="q-tab" type="button" role="tab" aria-selected="false">审阅中</button>
  <button class="q-tab" type="button" role="tab" aria-selected="false">已发布</button>
</div>

切换的是页面时用链接，当前项写 aria-current="page"。

数据概览 .q-stats

几个关键数字排成一行：灰色小标签在上，30px 的粗体数字在下。放不下时自动换行。最多放四个。

文档
128
已发布
96
总字数
28,565

</dl>

表格 .q-table

把列对齐了的列表。表头是灰色小标签，第一列是中等字重的主文字。没有边框、斑马纹和悬停底色。

标题 状态 字数 更新
写作规范 已发布 3,410 04.21
定价调整说明 审阅中 1,875 04.28
周会纪要模板 草稿 520 04.15 
<div class="q-table-wrap">
  <table class="q-table">
    <thead>
      <tr>
        <th>标题</th>
        <th>状态</th>
        <th class="q-num">字数</th>
        <th class="q-num">更新</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>写作规范</td>
        <td><span class="q-status q-status--success">已发布</span></td>
        <td class="q-num">3,410</td>
        <td class="q-num q-muted">04.21</td>
      </tr>
      <tr>
        <td>定价调整说明</td>
        <td><span class="q-status q-status--warning">审阅中</span></td>
        <td class="q-num">1,875</td>
        <td class="q-num q-muted">04.28</td>
      </tr>
      <tr>
        <td>周会纪要模板</td>
        <td><span class="q-status">草稿</span></td>
        <td class="q-num">520</td>
        <td class="q-num q-muted">04.15</td>
      </tr>
    </tbody>
  </table>
</div>
  • 数字和日期的单元格加 .q-num：等宽字体，右对齐。对应的表头也加上。
  • 次要的列加 .q-muted，变成最浅的灰。
  • 外面包一层 .q-table-wrap，手机上放不下时可以横向滑动。
  • 不超过五列。再多就把次要的列挪到详情页。
  • 桌面端文字是 20px，和列表一样大。手机上是 16px。

没有数据的时候

在表格的位置放一句灰色的话，需要的话下面跟一个按钮。不用插图。

没有符合条件的文档。

<p class="q-meta">没有符合条件的文档。</p>

状态 .q-status

文字前面一个 8px 的圆点。颜色只在圆点上，文字不变色。

草稿 审阅中 已发布 发布失败 
<div class="q-checks">
  <span class="q-status">草稿</span>
  <span class="q-status q-status--warning">审阅中</span>
  <span class="q-status q-status--success">已发布</span>
  <span class="q-status q-status--danger">发布失败</span>
</div>

标签 .q-tag

14px 的灰色小字，浅灰底，4px 圆角，和行内代码是同一种做法。用于「测试版」「只读」这类附加说明。

段落评论 测试版 
<div class="q-row">
  <span class="q-row-title">段落评论</span>
  <span class="q-tag">测试版</span>
</div>
