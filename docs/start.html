开始

开始使用

Quiet 由两个 CSS 文件组成：tokens.css 放全部变量，components.css 放基础样式和组件。不依赖任何框架，也不需要构建。

引入文件

把两个文件复制到项目里，在页面里引入，再加载 Inter 和思源黑体两个字体。<html> 上要写 lang="zh-CN"。

<html lang="zh-CN">
  <head>
    <link rel="preconnect" href="https://fonts.googleapis.com" />
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@100..900&family=Noto+Sans+SC:wght@400;500;700&display=swap" rel="stylesheet" />
    <link rel="stylesheet" href="tokens.css" />
    <link rel="stylesheet" href="components.css" />
  </head>

写第一个页面

每个页面都是同一个骨架：顶栏，下面一个居中的容器，容器里是若干个「标签 + 内容」的分组。先从五种页面里选一种，再往里填内容。

<header class="q-topbar">
  <a href="/">潮池</a>
  <span class="q-topbar-sep">/</span>
  <a href="/pricing">价格</a>
</header>

<main class="q-page q-page--airy">
  <div class="q-stack q-stack--loose">
    <h1 class="q-title">让团队安静地写长文</h1>
    <div class="q-actions">
      <a class="q-button q-button--primary" href="/signup">免费开始</a>
    </div>
  </div>

  <section class="q-section">
    <h2 class="q-section-label">价格</h2>
    <ul class="q-list">
      <li>
        <div class="q-row">
          <span class="q-row-title">团队版</span>
          <span class="q-row-meta">每人每月</span>
          <span class="q-row-date">¥48</span>
        </div>
      </li>
    </ul>
  </section>
</main>

在 Tailwind CSS v4 里用

在全局 CSS 里按这个顺序导入。之后可以直接写 text-primary、text-quaternary、bg-tertiary、bg-inverse、border-primary、max-w-measure、link-body 这些工具类，颜色会随深浅色自动切换，不用写 dark: 前缀。

@import "tailwindcss";
@import "./quiet-design-system/tokens.css";
@import "./quiet-design-system/tailwind-theme.css";

交给 AI

仓库里的 DESIGN.md 是写给 AI 看的完整规范，内容和这个网站一致。在新项目里可以这样说：

按这个仓库里的 DESIGN.md 做页面，直接使用 tokens.css 和 components.css，
不要自己定义颜色和字号。先从「五种页面」里选一种再动手。

深色模式

默认跟随系统。要强制指定，在 <html> 上加 data-theme="light" 或 data-theme="dark"。这个网站右上角的按钮就是在改这个属性。

<html lang="zh-CN" data-theme="dark">

字体是怎么加载的

  • 苹果设备上中文用系统自带的苹方，不会下载思源黑体。
  • 其他设备从 Google Fonts 按需下载思源黑体，只下载页面用到的那部分字。
  • Google Fonts 加载失败时会回退到系统字体。Windows 上是微软雅黑，它没有 500 字重，列表里的主文字和附注会一样粗。读者主要在这类网络环境的话，建议把两个字体下载下来自己托管。

换成自己的风格

  • 品牌色：改 --brand。它只出现在一条 20×4px 的短线上。
  • 状态色：改 --danger、--success、--warning。
  • 字体：改 --font-sans。这套设计依赖 400、500、700 三档字重，换字体时确认它们都有。
  • 英文页面：把 lang="zh-CN" 改成 lang="en"，行高和字距会自动换成西文的取值。
  • 栏宽：改 --measure 系列变量。

仓库里有什么

  • tokens.css 全部设计变量
  • components.css 基础样式和组件
  • tailwind-theme.css Tailwind v4 主题
  • DESIGN.md 写给人和 AI 的完整规范
