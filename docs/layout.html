基础

间距与布局

间距以 4px 为基准，布局永远是居中的一栏。

常用间距

  • 6px 桌面端列表的行距
  • 8px 主文字和附注之间，按钮之间
  • 16px 页面左右留白，标签到内容
  • 20px 段落之间，标签页之间
  • 24px 表单字段之间
  • 32px 文章页和应用页的区块之间
  • 64px 区块之间，页面上下留白
  • 128px 介绍页的上下留白

区块之间 64px，标签到内容 16px，差了四倍。哪些东西是一组，靠这个差距就能看出来，不需要卡片和分隔线。

三种栏宽

  • 576px 列表页 --measure-narrow
  • 672px 介绍页、表单页 --measure
  • 768px 文章页、应用页 --measure-wide

一个页面只用其中一种。手机上三种没有区别，都是屏幕宽度减去左右各 16px。

页面骨架

┌──────────────────────────────────────────┐
│ ☰  站点名 / 当前页                    ◐  │  顶栏 56px，粘顶

│        │ 分组标签              │          │
│        │ 列表行 ………… 日期     │  ≤768px  │
│        └──────────────────────┘          │
│               64px                       │
└──────────────────────────────────────────┘

断点

  • 640px 列表行变成一行，表格变成大字
  • 768px 页面标题 36px
  • 1024px 页面标题 40px
  • 1280px 文章页上下留白 80px

圆角、阴影和动效

  • 圆角只有三种：4px 用于行内代码、标签和小图标；8px 用于图片、代码块、输入框和对话框；全圆用于按钮、开关、头像和强调短线。
  • 阴影只有一种：一圈 0.5px 的描边加极轻的投影。它只用在浮起来、能按的东西上：按钮、小胶囊、对话框。
  • 过渡只有一种：150ms，只用于颜色和背景色。开关的滑块是唯一的位移。没有入场动画。
