基础

颜色

所有颜色都从一条中性色阶取值，通过语义变量使用。组件里不直接写色值。下面每一行右边的值是当前模式下实际生效的值，点右上角的按钮切换深浅色，它们会跟着变。

文字

四级灰度承担全部层级。

  • --text-primary 标题、正文、主文字 #171717
  • --text-secondary 大号引言 #525252
  • --text-tertiary 日期、引用、提示 #737373
  • --text-quaternary 附注、图标、占位文字 #a1a1a1
  • --text-label 分组标签、表头 #a1a1a1
  • --text-inverse 主按钮上的文字 #ffffff

深色模式下文字用的是带透明度的白：90%、70%、50% 和 32%，不是固定的灰色值。分组标签在深色下提亮一级，否则看不清。

背景

页面是纯白或纯黑。不给区块加底色来分区，用留白。

  • --bg-page 页面、顶栏、导航层 #ffffff
  • --bg-secondary 小胶囊的悬停态 #fafafa
  • --bg-tertiary 代码、输入框、标签 #f5f5f5
  • --bg-elevated 按钮、对话框 #ffffff
  • --bg-hover 透明按钮的悬停层 黑 8%
  • --bg-inverse 主按钮 #171717
  • --veil 对话框后面的遮罩 白 80%

品牌色和状态色

颜色的面积越小越好。不做彩色的实心按钮、彩色的提示条、彩色的标签。

  • --brand 强调短线，一页一次 #fc532a
  • --danger 错误提示、危险按钮的文字 #d93036
  • --success 状态圆点 #2f9e63
  • --warning 状态圆点 #e5a000

线条和选中

  • --border-primary 引用和提示的左边线、横线 黑 12%
  • --border-secondary 更淡的线 黑 9%
  • --selection-bg 选中文字的底色 蓝 10%
  • --selection-text 选中文字的颜色 蓝

中性色阶

上面的语义变量都从这条色阶取值。平时不直接用它，只在定义新的语义变量时用。

  • --neutral-50 #fafafa
  • --neutral-100 #f5f5f5
  • --neutral-200 #e5e5e5
  • --neutral-300 #d4d4d4
  • --neutral-400 #a1a1a1
  • --neutral-500 #737373
  • --neutral-600 #525252
  • --neutral-700 #404040
  • --neutral-800 #262626
  • --neutral-850 #1d1d1d
  • --neutral-900 #171717
  • --neutral-950 #0a0a0a
