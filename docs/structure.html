组件

容器与分组

每个页面都由同样的几层套起来：一个居中的容器，里面是若干个分组。

页面容器 .q-page

居中的单栏，左右留白 16px，区块之间 64px。用修饰类选择栏宽：

  • .q-page 表单页 672px
  • .q-page--airy 介绍页，上下留白加倍 672px
  • .q-page--narrow 列表页 576px
  • .q-page--article 文章页，区块间距 32px 768px
  • .q-page--app 应用页，区块间距 32px 768px 
<main class="q-page q-page--airy">
  …
</main>

分组 .q-section

一个灰色小标签加一段内容，两者相距 16px。内容可以是列表、表单、表格或一段正文。这是页面上最常见的结构。

功能

  • 长文编辑 标题、引用、代码和图片
  • 版本记录 每次保存都能找回 
<section class="q-section">
  <h2 class="q-section-label">功能</h2>
  <ul class="q-list">
    <li>
      <div class="q-row">
        <span class="q-row-title">长文编辑</span>
        <span class="q-row-meta">标题、引用、代码和图片</span>
      </div>
    </li>
    <li>
      <div class="q-row">
        <span class="q-row-title">版本记录</span>
        <span class="q-row-meta">每次保存都能找回</span>
      </div>
    </li>
  </ul>
</section>

标题区 .q-header

页面标题在左，主按钮在右，放不下时按钮换到下一行。用在应用页的开头。

竖排 .q-stack

把几个元素从上到下排开，相距 20px，和段落间距相同。.q-stack--loose 是 24px，用在标题、引言和按钮之间。
