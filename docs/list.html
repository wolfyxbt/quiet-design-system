组件

列表

成组的内容都先试着排成列表。一行由几种零件自由组合，桌面上排成一行，手机上折成上下几行。

零件

  • .q-row-icon 20px 的小图标，可选
  • .q-row-title 主文字，中等字重
  • .q-row-meta 附注，最浅的灰
  • .q-row-date 等宽的日期、价格或数字，靠右
  • .q-row-glyph 外链箭头之类的小符号
  • .q-row-main 包住主文字和附注，手机上保持并排
  • .q-row-end 行尾的控件，靠右

不是链接的行

没有目标页面的行用 <div class="q-row">。样子一样，只是悬停时不出现下划线。上面「图标、名称、角色和时间」里的两行就是这样。

行尾带控件

设置项这类行，把开关放在行尾。加上 .q-row--inline，手机上也保持一行。

<ul class="q-list">
  <li>
    <label class="q-row q-row--inline">
      <span class="q-row-main">
        <span class="q-row-title">每周摘要</span>
        <span class="q-row-meta">周一早上的一封邮件</span>
      </span>
      <input class="q-switch q-row-end" type="checkbox" checked />
    </label>
  </li>
  <li>
    <label class="q-row q-row--inline">
      <span class="q-row-main">
        <span class="q-row-title">产品动态</span>
        <span class="q-row-meta">有新功能时通知我</span>
      </span>
      <input class="q-switch q-row-end" type="checkbox" />
    </label>
  </li>
</ul>

行距

  • 桌面端行与行相距 6px。
  • 手机上每行的零件上下堆叠，行距放大到 16px，带图标时是 32px。
  • 桌面端主文字超长时截断成一行。
