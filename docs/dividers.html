组件

分隔与页脚

区块之间靠留白分开。只有下面几种情况会用到线。

斜纹带 .q-hatch

8px 高的细斜纹，横跨整个视口。只用来分开文章正文和后面的「延伸阅读」，一页最多一条。这一页的最下面就有一条。

<div class="q-hatch"></div>

强调短线 .q-tick

20×4px 的品牌色短线，放在「延伸阅读」的标签上方。这是品牌色唯一出现的地方。紧跟在它后面的标签会自动深一级。

延伸阅读

  • 四级灰度就够了
  • 为什么只用一栏 
<section class="q-section">
  <div class="q-tick"></div>
  <h2 class="q-section-label">延伸阅读</h2>
  <ul class="q-list">
    <li>
      <a class="q-row" href="../writing/four-grays.html"><span class="q-row-title">四级灰度就够了</span></a>
    </li>
    <li>
      <a class="q-row" href="../writing/one-column.html"><span class="q-row-title">为什么只用一栏</span></a>
    </li>
  </ul>
</section>

横线

正文里的 <hr> 是一条 1px 的细线，上下各留 24px，用来分开文章的两个部分。它只在正文里用。

示例框 .q-demo

写文档时用：上下各一条细线，中间放真实的组件，后面跟一段代码。这个网站的文档页里到处都是它。

页脚 .q-footer

页面最后一行 16px 的灰色小字：版权和几个链接。不分栏。
